# ALIGN PILATES

체형 교정과 필라테스의 기본 원리, 역사, 기초 동작을 소개하는 정적 웹사이트입니다.

## 폴더 구성

- `index.html`: 사이트 화면, 스타일, 동작 기능이 들어 있는 메인 파일
- `assets/pilates-hero.png`: 첫 화면에 표시되는 필라테스 이미지
- `.nojekyll`: GitHub Pages가 파일을 그대로 제공하도록 하는 설정
- `.gitignore`: 운영체제 및 편집기에서 생기는 불필요한 파일을 제외하는 설정

## 내 컴퓨터에서 미리 보기

`index.html` 파일을 더블 클릭하면 웹 브라우저에서 바로 확인할 수 있습니다.

## GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더 안의 파일을 저장소 최상위에 모두 올립니다.
3. 저장소의 **Settings → Pages**에서 배포 소스를 **Deploy from a branch**로 선택합니다.
4. 브랜치는 `main`, 폴더는 `/ (root)`를 선택하고 저장합니다.

사이트는 서버 기능 없이 HTML, CSS, JavaScript만으로 동작하며 이미지 경로는 GitHub Pages의 하위 경로에서도 열리도록 상대 경로를 사용합니다.
